# Замыкания

Лист: `javascript/scope/closures`. Приоритет: 20 (27 вопросов, 5 сборников из 6). Урок уже есть: `content/frontend/javascript/scope/closures.mdx`.

## Что обязательно знать

- **Замыкание** — функция вместе с окружением, в котором она создана. В спецификации у каждой функции есть внутреннее поле `[[Environment]]`, оно запоминается при создании (`OrdinaryFunctionCreate`). При вызове новое окружение функции ссылается на него как на внешнее.
- Функция хранит **ссылку на окружение, а не копию значений**. Поэтому она видит текущее значение переменной, а не значение на момент создания.
- Замыкание создаёт **каждая** функция в JavaScript. Вопрос лишь в том, переживает ли она внешнюю функцию.
- **Зачем:** приватное состояние (счётчик, кэш, модульный паттерн), фабрики функций, частичное применение и каррирование, обработчики и колбэки с контекстом, `debounce`/`throttle`/`once`/`memoize`.

## Тонкие места

- **Цикл с `var` и таймер:** все колбэки видят одну переменную. Решения — `let` (новая привязка на итерацию), IIFE, `forEach`.
- **Устаревшие значения в React:** колбэк эффекта или обработчик видит состояние того рендера, в котором создан. Отсюда функциональные обновления `setCount(c => c + 1)`, `useRef`, `useEffectEvent` (React 19.2).
- **Память:** движок держит всё окружение, на которое ссылаются живые функции. Если большое значение попало в окружение, где живёт долгоживущий колбэк (обработчик, таймер, подписка), оно не будет собрано. V8 держит только те переменные, которые используются хоть одним замыканием этого окружения. Но одно окружение общее для всех внутренних функций: если одна использует `bigData`, его держат все. Связь с memory.md.
- **IIFE** `(function () {})()` нужна была для изоляции до модулей и `let`. `function foo(){}()` — синтаксическая ошибка: `function` в начале инструкции разбирается как объявление. Решения: обернуть в скобки или поставить `void` или `!`.
- **Каррирование и частичное применение** — разное. Каррирование превращает `f(a, b, c)` в `f(a)(b)(c)`. Частичное применение фиксирует часть аргументов: `f.bind(null, a)`.
- **Приватность через замыкание и через `#field`.** `#field` — встроенная приватность классов, проверяется движком и видна в отладчике. Замыкание даёт приватность без классов, но каждый экземпляр хранит свои копии функций.

## Что изменилось

- Сама механика не менялась.
- React 19.2: `useEffectEvent` — официальный способ читать свежие пропсы и состояние из эффекта без добавления в зависимости. Это ответ на главную «замыкательную» боль в React.
- Явное управление ресурсами (`using`, ES2027) уменьшает потребность в ручных функциях очистки, которые часто держат замыкания.
