# Регулярные выражения

Лист: `javascript/regex`. Приоритет: 109 (10 вопросов). На собеседованиях спрашивают редко, в работе — постоянно: валидация, разбор, поиск, замена.

## Что обязательно знать

- **Создание:** литерал `/\d+/g` или `new RegExp(pattern, flags)` — для динамического шаблона. Пользовательский ввод в шаблоне экранировать: `RegExp.escape(str)` (ES2025).
- **Флаги:** `g` — все совпадения, `i` — регистр, `m` — `^` и `$` по строкам, `s` — `.` включает перевод строки, `u` — Unicode, `v` — Unicode с множествами (ES2024), `y` — «липкий» поиск с `lastIndex`, `d` — индексы групп.
- **Методы:** `test`, `exec`, `str.match`, `str.matchAll` (итератор всех совпадений с группами, требует `g`), `str.replace` / `replaceAll` (функция замены, `$<name>`), `str.split`, `str.search`.
- **Группы:** `(…)` захватывающие, `(?:…)` незахватывающие, `(?<name>…)` именованные (`match.groups.name`), обратные ссылки `\1`, `\k<name>`.
- **Проверки:** `(?=…)`, `(?!…)` вперёд, `(?<=…)`, `(?<!…)` назад.
- **Квантификаторы** жадные (`.*`) и ленивые (`.*?`).
- **Unicode:** без `u`/`v` эмодзи — два символа. `\p{L}` — любая буква любого языка, `\p{Script=Cyrillic}`. Для кириллицы `[а-я]` не покрывает `ё` — частая ошибка; `[а-яё]` или `\p{Script=Cyrillic}`.

## Тонкие места

- **`lastIndex` у регулярки с `g` или `y` сохраняется между вызовами:** `re.test('a')` дважды подряд может дать `true`, потом `false`. Опасно хранить такую регулярку в модуле и вызывать `test` многократно.
- **Катастрофический возврат (ReDoS):** шаблоны вроде `(a+)+$` на длинной «почти подходящей» строке зависают надолго. Это уязвимость, если шаблон или строка приходят от пользователя.
- **Валидация email регуляркой** — только грубая проверка. Точная проверка — письмо с подтверждением. Для полей формы — `type="email"` и Constraint Validation API (html/forms/validation).
- **`replace` со строкой** заменяет первое вхождение, `replaceAll` или флаг `g` — все. В строке замены `$&`, `$1`, `$<name>` имеют особый смысл.
- **`split` с группой** включает захваченные разделители в результат.

## Что изменилось

- ES2024: **флаг `v`** — разность и пересечение множеств `[\p{L}--[a-z]]`, свойства строк `\p{RGI_Emoji}` (Baseline широко).
- ES2025: **`RegExp.escape`** (Baseline недавно, 05.2025); **модификаторы** `(?i:abc)` — флаг для части шаблона (Chrome 125, Firefox 132, Safari 26); **повторяющиеся имена групп** в разных ветках `|` (Chrome 125, Firefox 129, Safari 17).
- На стадии 3: границы буфера `\A`, `\z`, `\Z`; описание «наследия» RegExp (`RegExp.$1` и т. п.).

## Идеи для практики

- **Задачи с редактором:** разобрать строку `key=value; key2=value2` в объект через `matchAll` и именованные группы; подсветка совпадений поиска с экранированием ввода (`RegExp.escape`); нормализация телефона.
- **Задача на ошибку:** глобальная регулярка в модуле с `test`, которая «через раз» не срабатывает; `[а-я]` без `ё`.
- **Карточки:** флаги; ReDoS — что это и как избежать; почему email не валидируют только регуляркой.
