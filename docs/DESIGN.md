# LIC · Дизайн: логика интерфейса и визуальный язык

> Документ отвечает на вопрос «как пользователю удобно и приятно учиться», так же подробно, как [TRAINERS.md](TRAINERS.md) отвечает на вопрос «как устроено обучение».
> Правила, обязательные для кода (FSD, токены, палитра, контраст), — в [CLAUDE.md](../CLAUDE.md). Здесь — почему и как именно.
> Составлен 09.11.2026. Визуальные макеты ключевых экранов в палитре платформы: https://claude.ai/artifact/RBkqbQpYUfXjnyc86ziUa6

## 0. Что не так сейчас

Аудит по скриншотам текущих экранов (09.11.2026):

| Экран | Проблема | Почему это плохо |
|---|---|---|
| Главная | Объясняет, что такое LIC, и показывает список специальностей | Человек приходит каждый день, чтобы **заниматься**, а не читать о платформе. Главный вопрос «что мне делать сейчас?» остаётся без ответа |
| Специальность | Плоский список из 25 блоков с полосками 0 % | Нет пути: непонятно, с чего начать и что дальше. Траектория из пяти этапов есть в плане, но не в интерфейсе |
| Тема | Одна длинная страница: цели, практика, Learn, Implement, Confirm подряд | Три шага LIC — главная идея платформы — не видны как шаги. Нет оглавления, нет «следующей темы», практика вклинивается перед объяснением |
| Сессия | Шапка сайта, служебная строка «Элементов в ветке: 30 · в изучении: 0…», ссылка на тему внизу | Отвлекает от вспоминания. Цифры говорят языком базы данных, а не человека |
| Задача | Условие, редактор и результаты в одной узкой колонке | На задачах программирования удобно, когда условие и код видны одновременно: экран делится на две части |
| Везде | Светлая тема, синий акцент по умолчанию, рамки у всего | Нет своего лица. Рамки у каждого блока дают шум вместо иерархии |

## 1. Принципы

1. **Сначала «что делать сейчас».** На каждом экране одно главное действие, оно заметнее всего остального. Вторичные действия — тише.
2. **Спокойный фокус.** Тёмная монохромная палитра, много воздуха, минимум рамок. Яркость — только у того, что важно в этот момент: главная кнопка, результат проверки, прогресс.
3. **Путь виден всегда.** Где я в курсе, сколько пройдено, что следующее — без поиска.
4. **Практика в режиме фокуса.** Во время повторения и решения задач навигация сайта уходит, остаётся только задание.
5. **Клавиатура — первоклассный способ работы.** Всё основное делается без мыши, подсказки по клавишам видны.
6. **Честная мотивация.** Прогресс, регулярность за неделю, «на сегодня всё» — спокойно и правдиво. Никаких конфетти за каждый клик, сгорающих жизней, обнуляемых серий, таймеров и оценок времени.
7. **Обучение важнее красоты.** Если красивое мешает понять или вспомнить, побеждает понятное.

Ориентиры:
- **Boot.dev и Exercism** — рабочее пространство задачи;
- **Frontend Masters** — плеер курса с оглавлением;
- **Brilliant** — урок по шагам с вопросами внутри;
- **Anki и Duolingo** — ежедневное повторение без лишнего;
- **Linear** — тёмный интерфейс, клавиатура, палитра команд по ⌘K.

## 2. Сценарии

| Сценарий | Как часто | Что нужно человеку | Что даёт интерфейс |
|---|---|---|---|
| **Ежедневное занятие** | Каждый день | Быстро начать, не думать, с чего | «Сегодня»: повторение одной кнопкой, затем «продолжить тему» |
| **Изучить новую тему** | Несколько раз в неделю | Понять, потренироваться, закрепить | Тема как три шага: Learn → Implement → Confirm с прогрессом |
| **Решить задачу** | Часто | Видеть условие и код вместе, быстро запускать | Рабочее пространство на две части, Ctrl/⌘+Enter, подсказки по ступеням |
| **Подготовка к собеседованию** | Перед собесами | Прогнать ветку целиком, найти слабые места | Свободная тренировка по ветке, «только трудные», отчёт о слабых темах |
| **Найти тему или термин** | Время от времени | Быстро открыть нужное | Поиск по ⌘K: темы, термины, задачи |
| **Вернуться после перерыва** | Иногда | Не утонуть в накопившемся | Мягкий режим: ограничение повторений на день и честное «вот сколько осталось» |

## 3. Информационная архитектура

### 3.1. Навигация

**Десктоп (от 1024 px):** узкая левая панель, сворачивается в иконки.

```
┌──────────┬──────────────────────────────────────────┐
│ LIC      │                                          │
│          │                                          │
│ ◉ Сегодня│              контент экрана              │
│ ▤ Курс   │                                          │
│ ↻ Практика (24)                                     │
│ ▥ Прогресс                                          │
│          │                                          │
│ ⌕ Поиск ⌘K                                          │
│ ⚙ Настройки                                         │
└──────────┴──────────────────────────────────────────┘
```

**Телефон:** нижняя панель из четырёх вкладок: Сегодня, Курс, Практика, Прогресс. Поиск — иконка в верхней строке.

**Режим фокуса** (сессия практики, рабочее пространство задачи): панели нет. Сверху тонкая строка: «× выйти (Esc)», прогресс, счётчик.

### 3.2. Иерархия курса

```
Специальность (Frontend)
└─ Этап траектории (1. Фундамент … 5. Специализация)
   └─ Блок (JavaScript)
      └─ Модуль (Области видимости и замыкания)
         └─ Тема (Замыкания)  ← единица обучения: Learn · Implement · Confirm
```

Этапы траектории из [FRONTEND-PLAN.md](FRONTEND-PLAN.md) (раздел 8) становятся главным способом показать курс: человек видит путь, а не каталог.

### 3.3. Адреса

Текущие адреса сохраняются: `/frontend/javascript/scope/closures`. Добавляются:
- `/today` — главная для вошедшего, `/` ведёт на неё;
- `/practice` — вместо `/review`, старый адрес перенаправляется;
- `/progress`;
- `/settings`;
- `#learn`, `#implement`, `#confirm` у темы — какой шаг открыт.

## 4. Экраны

У каждого экрана: цель, раскладка, состояния, телефон.

### 4.1. Сегодня (главная)

**Цель:** за 3 секунды понять, чем заняться, и начать одной кнопкой.

```
Доброе утро · понедельник, 9 ноября          на этой неделе 5 из 7 дней ▮▮▮▮▮▯▯

┌───────────────────────────────────────────────┐ ┌───────────────────────┐
│ Повторение                                    │ │ Неделя                │
│ 24 карточки и задачи · 16 повторений, 8 новых │ │ пн вт ср чт пт сб вс  │
│                                               │ │ ▮  ▮  ▮  ▯  ·  ·  ·   │
│ [ Начать повторение  ⏎ ]                      │ │ 86 % верных           │
└───────────────────────────────────────────────┘ └───────────────────────┘

Продолжить
┌───────────────────────────────────────────────┐
│ JavaScript › Замыкания                        │
│ Learn ✓  Implement 2/4  Confirm —             │
│ [ Продолжить ]                                │
└───────────────────────────────────────────────┘

Дальше по пути · Этап 1. Фундамент — 3 из 48 тем
  ○ Event loop          J
  ○ Промисы и async     J
  ○ Каскад и специфичность ✓
```

**Состояния:**
- **первый вход** — выбор специальности и короткое «как устроено занятие» в три шага;
- **повторять нечего** — «Повторение на сегодня закончено. Следующее — завтра, 8 элементов» и сразу «Продолжить тему»;
- **после перерыва** — «Накопилось 140. Сегодня предлагаю 40» с возможностью изменить.

**Телефон:** одна колонка, карточка повторения первой, неделя под ней свёрнута в одну строку.

### 4.2. Курс (специальность)

**Цель:** увидеть путь и своё место на нём.

```
Frontend                                         12 % · 28 из 231 тем
HTML, CSS, браузер, JavaScript, TypeScript, React, Next.js…
[ Продолжить: Замыкания ]   уровень: Все · J · M · S

● Этап 1. Фундамент                               ━━━━━━━━──── 58 %
│  ┌─ HTML ──────────┐ ┌─ CSS ───────────┐ ┌─ JavaScript ────┐
│  │ 6/12 тем  ◔     │ │ 2/18  ◔         │ │ 9/28  ◑         │
│  └─────────────────┘ └─────────────────┘ └─────────────────┘
○ Этап 2. Типы и React                            ────────────  0 %
│  TypeScript · Основы React · Как устроен React · Хуки · Паттерны
○ Этап 3. Данные и Next.js
…
```

- **Этап** — вертикальная линия пути с узлами: пройден, текущий, впереди.
- **Блок** — карточка с кольцом прогресса, числом тем и признаком «есть уроки», «только практика» или «в плане».
- **Фильтр уровня** J, M, S приглушает темы другого уровня, но не прячет их.

**Состояние «тема ещё не наполнена»:** приглушённая, с подписью «готовится», но в дереве видна — путь целиком.

### 4.3. Блок и модуль

**Цель:** выбрать тему.

Модули — секции. Темы — строки списка:

```
Области видимости и замыкания                                 2 из 4
  ✓  Лексическое окружение                       J
  ◑  Замыкания                       Learn ✓ · Implement 2/4    J   →
  ○  this и способы вызова                       J
  ·  Модули и область видимости      готовится   M
```

**Статус темы** — по шагам LIC, а не одной полоской. Оценку времени не показываем: темп у всех разный, и цифра давит.

### 4.4. Тема — главный экран обучения

**Цель:** пройти тему по шагам, понимая, где ты.

```
┌──────────────┬───────────────────────────────────────────────┬──────────────┐
│ Модуль       │ JavaScript › Области видимости и замыкания    │ На странице  │
│ ✓ Лексич. окр│                                               │ Суть         │
│ ◑ Замыкания  │ Замыкания                              J       │ Как устроено │
│ ○ this       │ (✓) Learn · понять  (2) Implement  (3) Confirm│ Цикл и таймер│
│ · Модули     │ Пройдено ━━━━━━  Решено 2 из 4 ━━━─── 19 карт.│ В React      │
│              │                                               │ Ошибки       │
│              │ Текст урока в колонке 68 знаков …             │              │
│              │                                               │              │
│              │ [ Дальше: Implement → ]                       │              │
└──────────────┴───────────────────────────────────────────────┴──────────────┘
```

- **Шаги — степпер вверху,** закреплён при прокрутке. Каждый шаг — отдельный вид, а не якорь в длинной странице. У шага:
  - кружок: галочка (пройден), номер в акцентной обводке (текущий), номер в серой обводке (впереди);
  - название с русским пояснением: «Learn · понять», «Implement · применить», «Confirm · закрепить»;
  - статус словами: «Пройдено», «Решено 2 задачи из 4», «19 карточек и квизов»;
  - полоска прогресса шага.
  - **Learn:** объяснение, примеры, демо, вопросы «проверь себя» внутри текста.
  - **Implement:** задачи темы карточками с уровнем и статусом (не начата, в процессе, решена, решена с подсказками). Открытие задачи ведёт в рабочее пространство (4.6).
  - **Confirm:** короткая сессия по карточкам и квизам темы, затем самооценка «знаю → владею» с подсказкой платформы («все карточки выучены — похоже на „понимаю“»).
- **Слева** — соседние темы модуля, сворачивается. **Справа** — оглавление текущего шага, появляется от 1280 px.
- **Внизу шага** — следующее действие: «Дальше: Implement», затем «Confirm», затем «Следующая тема».
- **Цели темы** («После темы вы сможете») — в начале Learn, сворачиваются. В Confirm это чек-лист самопроверки.
- **Служебное** («Проверено 08.11.2026 · ECMAScript 2026») — мелко внизу шага Learn, не в шапке.

**Телефон:** шаги — вкладки под заголовком; соседние темы и оглавление — в выдвижной панели по кнопке «Содержание».

### 4.5. Сессия практики (режим фокуса)

**Цель:** вспоминать без отвлечений.

```
×  Esc        ▮▮▮▮▮▮▮▮▯▯▯▯▯▯▯▯▯▯▯▯  8 / 24                 ⌨ клавиши

                       ┌─────────────────────────────────┐
                       │ Вопрос · Замыкания       Новое  │
                       │                                 │
                       │   Чем debounce отличается       │
                       │   от throttle?                  │
                       │                                 │
                       │          Пробел — ответ         │
                       └─────────────────────────────────┘

          Насколько легко вспомнили? От ответа зависит, когда карточка вернётся.
  ┌───────────────── 1┐┌───────────────── 2┐┌───────────────── 3┐┌───────────────── 4┐
  │● Не вспомнил      ││● С трудом         ││● Вспомнил         ││● Легко            │
  │вернётся через     ││вернётся через     ││вернётся через     ││вернётся через     │
  │минуту             ││2 дня              ││6 дней             ││2 недели           │
  └───────────────────┘└───────────────────┘└───────────────────┘└───────────────────┘
```

- **Кнопки оценки** говорят на языке человека:
  - крупно — что произошло («Не вспомнил», «С трудом», «Вспомнил», «Легко»), а не термины алгоритма;
  - под этим словами — когда карточка вернётся;
  - клавиша — отдельной меткой в углу, не смешана со сроком;
  - цветная точка — тихий статус;
  - «Вспомнил» выделен как самый частый честный ответ.

- **Прогресс сегментами:** каждый элемент — отрезок, отвеченный окрашивается по результату (тихие статусные цвета).
- **Только нужное:** служебные цифры («в изучении», «новых на сегодня») — не здесь, а в итоге и в «Прогрессе».
- **Тема** — мелкая подпись в углу карточки, ссылка открывается в новой вкладке, чтобы не потерять сессию.
- **Клавиши:**
  - пробел / Enter — перевернуть;
  - 1–4 — оценить;
  - Esc — выйти с подтверждением, если ответы ещё сохраняются;
  - ? — список клавиш.

**Итог сессии:**

```
Готово · 24 элемента
Верно с первого раза 19 · 79 %       ▮▮▮▮▮▮▮▮▮▮▮▮▮▮▮▮▮▮▮▯▯▯▯▯

Что вернётся: сегодня 3 · завтра 8 · на неделе 13
Сложнее всего: Event loop (3 ошибки)  → открыть тему

[ Продолжить тему: Замыкания ]   [ На «Сегодня» ]
```

### 4.6. Рабочее пространство задачи (режим фокуса)

**Цель:** решать, видя условие, код и результат сразу.

```
×  Esc │ Замыкания / debounce с cancel и flush  Тяжёлая     ● Черновик сохранён  Задача 4 из 4
┌───────────────────────────────┬─────────────────────────────────────────┐
│ Условие │ Подсказки · 1 из 4 │ 🔒Разбор│ 1 function debounce(fn, ms) {    │
│─────────────────────────────── │ 2   …                                   │
│ Напишите debounce(fn, ms)…    │                                         │
│                               │                                         │
│                               ├─────────────────────────────────────────┤
│                               │ Тесты 5/7 │ Консоль │ Предпросмотр      │
│                               │ ✓ вызывает один раз после паузы         │
│                               │ ✗ flush возвращает результат            │
│                               │   ожидалось 42, получено undefined      │
└───────────────────────────────┴─────────────────────────────────────────┘
 [ ▶ Запустить тесты ⌘⏎ ]  Сбросить к заготовке        [ Сдаться и посмотреть решение ]
```

**После решения** (отдельный макет «Задача: решено»):

```
✓ Решено · Со второго запуска и с одной подсказкой. Вернётся через 2 дня.
Разбор: почему так · эталон (свернут, «сравнить со своим») · А если… · что спросят на собесе
▮▮▮▮▮▮▮ Все 7 тестов пройдены                                  Показать тесты
 [ Запустить ещё раз ]                   Это была последняя задача темы   [ Дальше: закрепить тему → ]
```

- **Две колонки с перетаскиваемой границей** (видимая ручка, работает и с клавиатуры). Справа редактор сверху, внизу вкладки «Тесты / Консоль / Предпросмотр» (предпросмотр — для React-задач), между ними тоже ручка. Размеры запоминаются.
- **Шапка:** где я (тема / задача), уровень, «Черновик сохранён», какая это задача в теме. Таймера нет.
- **Редактор:** имя файла и язык; подсказка, как выйти из редактора с клавиатуры (Esc, затем Tab); строка, связанная с упавшим тестом, подсвечена.
- **Слева вкладки:**
  - «Условие»;
  - «Подсказки» — лестница: открытые ступени, названия закрытых («приём», «каркас», «ключевая строка»), индикатор «1 из 4» и честная фраза: «С двумя подсказками и больше задача вернётся на повторение раньше». Последняя открытая подсказка показывается и под условием, чтобы не переключаться;
  - «Разбор» — с замком до решения или открытия решения.
- **Результат:**
  - упавший тест раскрыт и показывает «ожидалось / получено»;
  - прошедшие свёрнуты в строку «✓ 5 пройденных тестов», раскрываются по клику;
  - над списком — сегменты по тестам и «5 из 7 пройдено»;
  - успех — короткая спокойная анимация полосы тестов, вкладка «Разбор» открывается сама, вверху итог словами: как решено и когда вернётся.
- **«Дальше» появляется только после решения** (или после «Сдаться»): до этого главная кнопка одна — запуск. После решения запуск становится вторичным, а главной — «Дальше» с понятной целью: «следующая задача» или «закрепить тему».
- **«Сдаться и посмотреть решение»** — честное название вместо «Показать решение». Спрашивает подтверждение: «Задача вернётся на повторение скоро. Открыть решение?»
- **Телефон:** вкладки «Условие / Код / Результат» и кнопка запуска внизу экрана.

### 4.7. Карточки и квизы

- **Карточка:**
  - крупный текст по центру;
  - переворот — короткая анимация поворота от ребра (уже есть);
  - ответ на той же карточке, с тонким разделителем от вопроса — видно и вопрос, и ответ.
- **Квиз:**
  - варианты — крупные строки с буквой-клавишей (A, B, C, D); выбор цифрой или буквой;
  - после проверки у каждого варианта значок и пояснение, а не только цвет.
- **«Что выведет»:** код слева, поле ответа справа (на телефоне — друг под другом). После проверки — построчное сравнение «ваш вывод / настоящий».
- **«Порядок»:**
  - перетаскивание и клавиши (↑↓ с зажатым Alt);
  - на телефоне — касание по шагу добавляет его в ответ.

### 4.8. Прогресс

**Цель:** увидеть, что знания растут, и найти слабые места.

- **Активность:** тепловая карта по дням за полгода и «дней с занятиями» по неделям. Счётчика серии нет (решение — раздел 11).
- **Освоение:**
  - по этапам и блокам — сколько тем на каждом уровне (знаю, понимаю, применяю, владею);
  - по повторению — сколько элементов «выучено» (вышли из изучения), прогноз нагрузки на неделю.
- **Слабые места:** темы с наибольшим числом «Снова» и тем, что давно не открывались — с кнопкой «Тренировать».
- **Задачи:** решено по уровням, сколько с первого запуска.

### 4.9. Поиск ⌘K

Одно окно для навигации и поиска:
- темы;
- термины из карточек (открывает тему на нужном месте);
- задачи;
- команды («Начать повторение», «Переключить тему»).

Стрелки и Enter, история последних открытых.

### 4.10. Настройки

- **Темп:** новых в день и лимит сессии.
- **Код:** размер шрифта в коде.
- **Движение:** уменьшить анимации.
- **Вид:** показывать ли подсказки по клавишам.

## 5. Визуальный язык

### 5.1. Цвет

Палитра и контраст — в [CLAUDE.md](../CLAUDE.md). Как её применять:

- **Поверхности по ступеням светлоты** вместо рамок и теней:
  - фон — `ink-900`;
  - карточка — `ink-800`;
  - наведение и приподнятое — `ink-700`.

  Рамка `ink-700` толщиной 1 px — только там, где ступени недостаточно (поля ввода, разделители).
- **Главная кнопка** — светлая таблетка: фон `ink-100`, текст `ink-900`. Самый контрастный элемент экрана, поэтому главный.
- **Вторичная кнопка** — `ink-700` с текстом `ink-100`. **Третичная** — только текст `ink-300`, при наведении светлеет.
- **Акцент для прогресса и активного** (полосы, текущий шаг, ссылки, кольцо фокуса) — лавандовый **`#C7B8F0`**, утверждён 09.11.2026. Контраст 9,9:1 на фоне. Используется скупо: только то, что показывает движение и выбор.
- **Статусные цвета**, приглушённые, в тон палитре. Контраст проверен 09.11.2026:

| Токен | Цвет | Контраст на `ink-900` / `ink-800` |
|---|---|---|
| `good` | `#8FC4A2` | 9,1 / 7,5 |
| `warn` | `#D9B46E` | 9,2 / 7,6 |
| `bad` | `#E0959F` | 7,7 / 6,4 |
| `info` | `#9DB2E0` | 8,5 / 7,0 |
| `accent` | `#C7B8F0` | 10,0 / 8,2 |

  `bad` на `ink-700` даёт только 4,3, поэтому текст ошибки на приподнятых поверхностях не размещаем. Фоны статусов — тот же цвет с прозрачностью 12–16 % поверх поверхности.

- **Код** — на `ink-900` даже внутри карточки `ink-800`: код читается как отдельный слой. Подсветка синтаксиса — из тех же статусных оттенков и акцента, без кислотных цветов.

### 5.2. Типографика

- **Шрифты:** Inter (интерфейс, переменный, с кириллицей), JetBrains Mono (код).
- **Шкала:** 12 · 14 · 16 · 18 · 20 · 24 · 30 · 36 px. Основной текст интерфейса — 14–16, текст урока — 17–18 с интерлиньяжем 1,7, заголовок экрана — 30.
- **Колонка урока:** 64–72 знака (около 680 px при 17 px).
- **Цифры** в счётчиках и таймерах — моноширинные (`tabular-nums`), чтобы не прыгали.

### 5.3. Форма

- **Сетка отступов 4 px:** 4, 8, 12, 16, 24, 32, 48, 64.
- **Радиусы:**
  - 8 — поля и маленькие кнопки;
  - 12 — карточки;
  - 20 — крупные панели;
  - полное скругление — главные кнопки, бейджи, чипы, сегменты прогресса. Таблетки — визуальная рифма палитры.
- **Тени:** почти нет. В тёмной теме глубину даёт светлота поверхности. Тень — только у всплывающего (меню, ⌘K, модальные окна).
- **Иконки:** Lucide, толщина линии 1,75, размеры 16 и 20.

### 5.4. Движение

| Токен | Длительность | Где |
|---|---|---|
| `fast` | 150 мс | наведение, нажатие, смена вкладки |
| `base` | 200 мс | появление панелей, раскрытие подсказки |
| `slow` | 300 мс | переворот карточки, результат проверки, переход шага |

- **Кривые:** `ease-out` для появления, `ease-in` для исчезновения.
- **Смысл:** анимируется только изменение состояния, ничего «для красоты».
- **`prefers-reduced-motion`:** движение заменяется сменой прозрачности.

## 9. Как проверяем дизайн

- **Матрица проверки** для каждого нового экрана: три ширины (390, 1024, 1440) × клавиатура.
- **Скриншотные тесты Playwright** ключевых экранов: изменения вида видны в ревью.

## 11. Решения

Приняты 09.11.2026:

1. **Только тёмная тема.** Светлой нет и в настройках её нет. Токены всё равно смысловые: если светлая когда-нибудь понадобится, она добавится подменой токенов.
2. **Акцент `#C7B8F0`** утверждён: прогресс, активный шаг, ссылки, кольцо фокуса.
3. **Без счётчика серии.** Показываем регулярность: «на этой неделе 5 из 7 дней», тепловую карту и дни с занятиями.
   - **Почему:** серия обнуляется после одного пропуска. Это даёт тревогу, а после срыва люди часто бросают совсем.
   - **Что важно для интервального повторения:** регулярность, а не непрерывность. Недельная мера прощает пропуск и всё равно мотивирует.
4. **Никаких оценок времени:** ни «≈ 35 мин» у тем, ни «около 12 минут» у повторения, ни таймера в задачах. Темп у всех разный, цифра давит и ничего не даёт.
